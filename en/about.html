ONE NETWORK. MANY POSSIBILITIES.

An independent game about reasoning through routes and learning to read metro networks.

Text updated on 11 October 2026 · by Damiano Gasparotto

Why MetroMind

MetroMind is an independent project by Damiano Gasparotto. It starts with a simple question: when a journey must include several stations, which order and route are the most efficient?

Metro networks become a logic puzzle. Random missions, transfer penalties and automatic rides encourage planning before acting. Complete maps let players learn connections outside the game.

How it is built

Each network consists of stations and connections assigned to lines. The solution calculation tracks the current station, arriving line and already visited required stops. It searches for a minimum-cost route across the possible mission states.

Checks cover network connections, routes and automatic rides. Public source code, checks and credits are available on GitHub.

Sources and limitations

Networks are reconstructed from operator maps or data, linked from the city study pages. The diagrams are original, simplified and not to scale. Some railway services outside the metro are excluded; each city page explains its represented network.

MetroMind is not affiliated with transport operators. Times are fixed game rules. These maps are not a real travel information service.

Contact and corrections

To report an incorrect connection, include the city, line and station names. For game issues, also describe the level and the route you followed.

Open an issue on GitHub or visit the author’s public profile. GitHub issues are public: avoid including personal information.
